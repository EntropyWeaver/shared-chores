# Shared Chores

Aplicación web para gestionar tareas domésticas compartidas entre 2 y 6 compañeros de piso adultos.

Este repositorio forma parte del Module 1 de **AI Dev Tools Zoomcamp 2026**. El objetivo del ejercicio es practicar un flujo de desarrollo asistido por IA en el que la especificación se aprueba antes de generar código.

## Estado

Especificación y backlog aprobados. Las Tasks 1–4 están completadas: una persona puede registrarse, crear un hogar con código único o unirse a uno existente, respetando el límite de seis miembros.

## Funcionalidades previstas

- Crear un hogar compartido y añadir miembros mediante un código.
- Crear tareas puntuales o semanales y asignarlas manualmente.
- Mostrar a cada usuario sus tareas pendientes y vencidas.
- Registrar la finalización y conservar un historial.
